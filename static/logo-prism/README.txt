ShopSupport.ai — Logo Kit (Prism)
==================================

Official mark: a faceted 3D prism in brand teal with a warm lime top-right facet,
paired with the "shopsupport.ai" wordmark in Sora (gradient: white > teal > cyan,
with ".ai" in solid teal #00d4aa).

FILES
-----
shopsupport-lockup-gradient.svg  Primary lockup. Gradient wordmark. Use on dark backgrounds.
shopsupport-lockup-dark.svg      Lockup with solid WHITE wordmark + teal .ai. Dark backgrounds, simpler.
shopsupport-lockup-light.svg     Lockup for LIGHT backgrounds. Dark wordmark, brightened prism, teal .ai.
shopsupport-stacked.svg          Symbol centered above the wordmark. Square-ish, for avatars / social.
shopsupport-symbol.svg           Prism symbol only. Favicon, app icon, tight spaces.

COLORS
------
Teal accent     #00d4aa
Wordmark grad   #ffffff > #7fffe8 > #45c8ff
Warm facet      #d8ff85 > #34d9b0
Dark bg         #09090f

FONT
----
Wordmark is set in Sora SemiBold (600). The SVGs reference Sora via @import, which loads in
browsers and most design tools. When a tool blocks remote fonts (e.g. used as a flat <img>),
the wordmark falls back to a system sans at the correct size. For a 100% portable, pixel-perfect
master, the wordmark should be converted to outlines (vector paths) in a vector editor, or send
the Sora font file to have it outlined.

Clear space: keep at least the height of the prism symbol clear on all sides.
Minimum size: symbol no smaller than 20px; full lockup no smaller than 120px wide.
